# 3D 晶体结构与晶格缺陷分析工具

React + Vite + TypeScript + React Three Fiber 的材料科学可视化基础项目，用于展示面心立方晶格、空位缺陷、替位缺陷与刃型位错。

## 当前能力

- 三维晶格原子与最近邻连接
- 空位、替位和刃型位错模型切换
- 晶胞数量调整
- 晶面透明度调整
- X/Y/Z 正交方向与自定义法向量切片
- 基于结构包围盒实时计算切片多边形，超界显示空态且不修改原场景
- 切片法向箭头标注与沿法向自动/手动定位相机
- 选择“裁剪可见对象”模式；切片透明度与原参考晶面隔离
- 缺陷指标展示
- 三维旋转、缩放和结构观察
- 结构快照操作入口

## 启动

```bash
npm install
npm run dev
```

当前使用内置演示晶格数据，后续可接入 CIF 文件解析、晶面选择、晶格常数计算、位错密度分析、XRD 辅助数据和真实分子动力学结果。
